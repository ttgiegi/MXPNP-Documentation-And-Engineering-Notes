# MXPNP Manuals & Engineering Notes

Documentation and engineering notes for MXPNP, an experimental desktop pick-and-place platform.

## Documentation

- [User Guide and Manuals](https://github.com/ttgiegi/MXPNP-Documentation-And-Engineering-Notes/wiki)
- [Engineering Notes](https://github.com/ttgiegi/MXPNP-Documentation-And-Engineering-Notes/wiki)

The repository is the public documentation portal. The Wiki will be expanded over time with installation instructions, machine operation guidance, calibration procedures, troubleshooting notes, FAQs, and engineering decisions.

## Support

For questions, bug reports, or project discussion, please use the repository's [Issues](https://github.com/ttgiegi/MXPNP-Documentation-And-Engineering-Notes/issues) page.

> This repository contains documentation only. MXPNP source code is not hosted here.
